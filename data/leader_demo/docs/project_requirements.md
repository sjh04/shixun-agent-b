# 本地 Agent 项目验收需求

验收演示需要证明系统具备以下能力：

1. 能读取本地文档并基于真实文件内容回答，不能编造文件内容。
2. 能根据任务选择合适工具，例如计算、文件读取、文件搜索、表格分析和格式转换。
3. 能注入长期记忆，结合全局知识和历史对话给出回答。
4. 能保存本轮对话为 memory，供后续任务检索复用。
5. 工具调用失败或参数错误时，系统应结构化记录错误，不应直接崩溃。

推荐验收顺序：

- 先展示完整链路：memory 注入 → LLM 选择工具 → B3 执行工具 → ToolMessage 回写 → LLM 生成最终回答 → B5 保存记忆。
- 再展示不同工具能力。
- 最后展示 B1/B3/B5 进阶能力，如批量任务、工具缓存/统计、记忆检索/压缩/冲突管理。
